# Last Light

Unofficial fan site for The Last of Us, Part I. One static page: no build step, no dependencies.

- `index.html` is the whole site (styles, scripts, images and the Matcha Boom font are embedded).
- `fonts/` holds the original Matcha Boom files and the author's notes (free for personal and commercial use; check khurasanstudio.com/license for details).
- Languages: English and Russian, switched with the Translate button.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a repository and push this folder's contents to the `main` branch.
2. Repository Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repository>/`.

Images and official art belong to their respective owners. Replace them with your own before selling the site.
